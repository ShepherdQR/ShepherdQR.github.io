```

工作思路：速览，要点清单，顶层设计 // 加快推进

用软件辅助整理。

注意一段话之间的连接结构。注意主体性身份的体现。
```

### 结构：宏微结合 + 框架

- 站位；结构（世易时移）；标题（有事说事）；句子（干净，准确，理性）。

 



### 文体：事务性 + 演讲 + 公文

- 工作方案：意义 + 内容
- 通知：
- 信息稿/通讯：工作落实端的第一个完善的公文。短平快/时效性强
- 工作简报：初步成果/具体举措/基础数据
- 宣传稿件：亮点深挖 + 细致分析
- 汇报稿：经验 + 困难 + 需要的扶持 + 下一步计划
- 典型经验：
- 座谈发言稿：
- 宣讲稿/演讲稿：阶段性变化；感人
- 启动仪式讲话稿/主持词：拟面推广的经验；作为品牌标杆筹备；
- 先进事迹：推树先进
- 工作总结：成效较大的工作
- 述职报告：工作总结 + 个人角色与作用
- 工作思路/计划/要点：复盘要做深做细，引入纵深
- 文艺活动稿件：话剧/诗歌/歌曲/情景剧/快板/视频等形式
- 慰问信：
- 政务号/创刊词


- 时间逻辑/空间/因果/辐射

- 要写提纲。情感一气呵成。
- 多彩大美。绿色建设。
- 注意过渡段。内容要整齐。

先进事例的框架：根据维度
例如宣传员：
- 热爱工作：提高思想认识的努力/学习知识/培训
- 基础和专业知识：背景
- 信息收集和处理能力：大量信息的过滤/提炼/总结
- 成果：质量，速度，数量
- 被上级机关和主流媒体采用：效能，量化
- 建章立制：起草/讨论。
- 壮大队伍：角色/作用/举措；选拔人才，优化人才结构，教育培训，考核激励与保障
- 有阵地/载体/特色/质量/全局：载体丰富/形式多样/模式新颖，负责工作部分/成效/金点子/作用

其他框架可能：
- 心得：时间维度
- 讲话稿：逻辑
- 经验材料：【背景介绍+经验概述+简要效果】 + 【模式介绍 + 创新亮点 + 逻辑关系 + 工作成效】 + 【经验启示 + 下步计划】


通讯稿：
- 时间逻辑：动员部署（动员部署大会/组建领导小组/实施方案与考核方案/有序推进）；初步落实（推出各项举措/多点开花/亮点纷呈）；经验做法（提炼经验/模式抓手）；复盘（专项整治/整改落实）；创新举措（精品案例）。
- 业务逻辑：近期重点工作（近期的开展情况纳入考核体系，完善考核激励制度/深化成果运用）；日常工作；下步工作（例如试点工作，如何开展提供法律援助/守护营商环境）；特殊节点（高峰论坛；人才引进/政策解读/提升服务，惠企便民措施）。

- 专精特新的专栏文章。
- 通讯稿与工作简报。
- 高质量素材，一边素材，一边创作
- 切口要小而美。


- 演讲：句尾上扬 + 设问 + 连续排比 + 文字干净 + 大小词并用
- 强国有我的先锋旗帜。
- 记忆稿件：听录音，默写，大声背诵
- 选育管用
- 畅通联络对接渠道；完善诉调衔接机制。
- 迈出坚实步伐。向纵深推进。全面提速/发展动能持续增强/保持强劲势头/品质提档升级。持续增产创效/结构全面优化。
- 压茬推进重点产业项目。
