# [20世纪世界诗歌译丛](第三辑)英国当代诗选

## 诗句

### (Seamus Heaney,1939- )
```
凝结的阳光/镀金的砂砾

我们在房间里孕妇一般悠闲移动，
我们脑袋的旋转水晶球中，充满了干净的杉木搅拌器，
酸味牛奶的溅泼和汩汨声，
小铲子在潮湿奶油块上轻轻的拍击。


《布 洛 格》
河岸，长长的索具
终止在阔叶野草丛中
一片遮住水面的浮叶
漫向浅滩。

花园的肥土
很容易被擦伤，聚集在
你鞋跟印里的阵雨
是黑色的O

在“布洛格”—词中
有低低的连续敲击声
在有风的布尔树林
和大黄叶片中

结束得近乎突然，
仿佛那最后的“格”
外来人发现
难以驾驭。
【END】


柔和的上坡，元音的草地

水甜如蜜
太阳靠墙站着
像一个浅锅
变凉


此时蜡烛熔化
烛身形成经脉，
火格盘旋
女人在我身后


我穿过潮湿的叶子，
谷壳，秋天无力的锚爪


那是寒冷的一天
刺痛的寂静，风吹着


《收 获 结》
当你编织收获结时
你把内心成熟的寂静
编织在不会生锈的麦秸中
当它越编越紧，弯成
一个明亮的日冕，
一个用后抛弃的稻草的爱之结。

那双衰老的握着白蜡树和藤杖的手
在一生的斗鸡游戏中轻拍鸡距的手
返回它们的天赋，专注地工作
直到你的手指梦游般地移动：
我辨认并触摸它，好像它是盲文，
从中收集未说出的一切。

如果我窥视它的金环
就能看见我们在铁路斜坡间行走
进人一个有高草和小蚊虫的黄昏，
蓝烟笔直升起，树篱里的旧床和犁，
厢房墙上贴着拍卖广告————
你的翻领上系着一条收获结，

我带着钓竿，开始想家
因为这些黄昏情绪高涨，你的手杖
用力抽打着杂草和灌木梢
长久地抽打，抽打，但什么
也没有惊起：那原始的乡土
依然在你手编的麦秸中沉默不语。

艺术的结局是宁静
可以做为这脆弱之物的题词
我把它钉在我们的杉木梳妆台上————
像一个变形的诱饵
后来谷神从中悄悄溜走
它却因其经过而磨光，并依然温暖。
【END】


我的双手垂人水中。
你是我可以触摸的，柔软的
记忆的水獭
在此时的水池中，
你翻过身仰泳
大腿每一次沉静、颤抖的划动
都重新使光倾斜
把凉爽汹涌到你的颈边
```


### (Tony Harrison,1937-)
```

这些人类的牺牲者，被铁链锁住在火刑柱上焚烧，是炽热的火炬照亮了走向婚床的君主。
———J.L.莫特利，《荷兰共和国的崛起》


你的生活全都成了碎片。


他从未乞求过。乞求邪恶！死亡的沉默
为他的生命加冕，而我，我将打开我的陷阱
为因为几便士就把他猛打的阶级
那些便士像微咸的眼泪落到我们的帽子里。
```

### (Douglas Dunn,1942-)
```
《当代爱情》
这是夏天，我们在一座
不是我们的房子里，坐在桌边
享受着租来的片刻宁静，
楼上的人走了。鸽子哄睡
幼鸽和病鸽，
群树把影子散开到草上，
玫瑰在我忽略的野地飘忽不定。
我们的生命振翅，我们不希望
比这更多的幸福，也没有更多爱情的表示
但我们，或是这个傍晚
怎样无人而寂静，我们活在
一种家庭之爱里，表面上显得孤单，
所有其他的生命磨损成树和阳光，
盼望猫来拜访。
【END】


在有露的草上带着一只手提箱
爱情小跑着到来，握着一只鞋停下。
跟她走！去开豪华轿车


或是孩子们在酥脆的叶子上奔跑


每一件东西中无形的破碎。
钢琴师命运中的一个错误。犬吠。
一辆狗拉轻便二轮车的轧轧声。愉快。


午餐，是惟一神教派的原则，巴尔扎克会这样告诉你
任何接近中午时看表的文学人物
都会毫不犹豫地赞同。午餐是资本的交易，
无论在蜗牛菜馆，火鸡店，还是便宜的意大利带骨肉馆。
在贫困或自负的外省，天才诞生，
愤怒的诗人遥望伦敦像遥望一片饭店的海洋.


倾听海洋控制它文雅的荒野，
尽管看到只有我的脚印使我害怕
以人的痕迹污染这片荒芜的海滩，
皮革在泥浆上的每一声咯吱都在抱怨，可你要去哪里？


我在这里削着时间，像削一根干木棍，
从日出到日落，在我不能说话的
舌头的呻吟和叹息中，
在议会外面，注视着他们，
就像他们，也一直在注视我一样
穿过我的仪器注视着他们
注视着。仁慈，还是邪恶？可是谁，
在这从前的舞台上，能说，或者认为它值得？
因为我忘了，我在那里，是过去还是现在。
```


### (Hugo Williams,1942-)
```

我们的幸运是永远
后退着穿过草地
朝向另一时代的边缘。


《沿着这些诗行》
于是你为她哭泣，诗坠落到纸上
仿佛它完全了解我们用什么组成我们从另一个人的
心里带走了什么————撕扯着喊叫着直到我们
多么笨拙地了解，在楼上和关起的门后我们出生
并对我们从世上借来的东西发生了兴趣。
【END】


《潮 汐》
黄昏前进，然后又后退
把我们的杯子和书像岛屿留在地板上。
我们在漂流，我和你，
彼此远离，就像这两本
我们刚刚放下的小说中的年轻勇士。
因为那是幸福：去独自漫游
被同一个月亮围绕，它的潮汐使我们想起自己，
想起我们的距离，和我们留在后面的东西。
灯开着，窗帘使光能够透人。
这些事物是承诺。无疑我们将回到它们。
【END】
```

### (Anne Stevenson, 1933-)
```
不久前的一天傍晚
我散步到高高的平石那里，
像孩子一样，我们过去常常躺在那里
等待星座。那是有雾的黄昏，
群山，一层层相异的柔和浓密的阴影
蟋蟀、纺织娘的刮擦声，
或者任何声音尖利无法扑灭的昆虫
锯开它们的道路，穿过一个又一个夏夜。
坐在石头上，
竭力望向远方，
陌生得仿佛
我看透了声音。仿佛一种紧张，
我身边的唠叨，变成了雾——
群山，也在安静地呼吸，太阳
悄悄坠落，穿过薄纱消失。


海鸥以为有虫的沙子
是为它们升起的，
孵化着它很少的权利，
输掉了它与水的战争。


几乎梦不到，这记忆中的盐池，
在一个充满透明水母的早晨赤裸着，
随潮汐和海鸥一起出去
在复原的海滩上放牧，
当海石竹在干燥的小径边闪耀，
当帆停止对水的切割
向着某个有名字的内陆港前进。
```

### (Tom Paulin, 1949-)
```
波浪在岸边沙沙响，如同浆过的丝绸。
少女们走下楼梯
进入一间亮灯的宽敞房间。
爱是一种危险，其次是孩子们。
日落时分，当我看见码头上
白色的灯塔，我感到眼泪流下。
但是我幸福得如同女人，打开门
听见了音乐。我看见的是你的脸。
我听见你的声音，你优雅的声音。
我越过水面凝视另一个海岸，
和一个在声音中睡眠的老妇人。

### (Peter Scupham, 1933-)
```
《旧餐具室》
太阳在钓一条玻璃鳟鱼，
杯子在涡卷形钩子上降落。

生命转变成骨瓷
她闪烁的蓓蕾和光泽。

油布闪耀成光的切片。
一个黯淡或灿烂的静止

可是从黑暗中，隐藏的寂静，
白色食物浮出暗淡的表面。

停泊在水罐边缘，一个长柄勺
摇摆着把微光浇在甜奶上

蔗糖碎成一片寒冷的银沙，
新烤的面包在湿布下散发香气。

一个黑社会，变白变哑，
伸入这新鲜空气的水流。
【END】


当秘密被保持，迷宫被穿过，
花园以一种同情的声音讲话
穿过否认它们自己的腐蚀
不需要名字的花朵。

### (Penelope Shuttle, 1947-)
```
《特鲁罗博物馆，三个新月形之物》
这么薄的金子
只有一个老妇人
会注意到它的重量

金色的弦月
来自黑暗
沉没的地区
从考古学的土壤中露出

新月形的妇女
没有投射出未开化的影子
一种生动的舞蹈
依然照亮她们的骨骼

我感到许多妇女的
情绪
她们戴着新月
像一串项链

她们克服了
冬天
当我依然冰冷

一只钟
轻微快速的拍击
继续
像草中
一只昆虫
脚的节奏

我徘徊在
上锁的
金色房间，
试图看见，
镰刀形状之外，
那三个妇女的脸

尖锐的影子艰难地呼吸，
脱落的皮肤像沾满灰尘的蛇
光在一阵剧烈的恶心中扭曲

一片嘴唇的碎片，
一条美如蛛丝的眉毛
存在了片刻

一张脸像霜打的羊齿草

管理员
把新月形之物
再次安全地锁起

她们是康华尔人，
他说，
在圣朱利奥特挖出来的，
是这片土地的标记，
不是为大英博物馆准备的

你为我买了
一张新月形之物的明信片
然后我们离开博物馆，
进入秋天
薄薄的金色残余物
【END】


《倾盆大雨》
一阵猛烈的雨落下，一场骨骼突出的倾盆大雨。
雨水嗥叫着，像一场驱逐。
白昼突然消失
夜晚在一处峭壁边缘踌躇
出于对困难的恐惧。例如,雨。

树叶代替了信，穿过邮筒，
湿树叶沿途吹送
渗过低矮的邮筒，
缓慢的侵略，
但被雨拯救。倾盆大雨。

我梦见荆棘，飞机和红马，
但很少梦见雨。

这生物旋转着网捕捉它的猎物，
我也梦见她
但几乎从未梦见雨。雨的网。

雨没有松弛。它有着
槲寄生的气味。可它是一件武器，抛出。
窗户因之闪烁出黑色。
我坐着观察一串串打结的雨。
我不想停止观察。如此肌肉发达的雨。

干燥的房屋，它的音乐和食物，
召唤窗边的我，
将我从一场正在淹没我的倾盆大雨中拖回。
我准备从窗边转身，
但仍停留了片刻，
注视模糊的烛焰
衬着黑暗的玻璃。

那里是倾盆大雨。这里是突然增强的光。
【END】


我等待，在火焰的悬崖边。
```
