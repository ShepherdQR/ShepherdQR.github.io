3- 西非：黄金砝码

特定社会文化要素，仅仅为该社会成员们而存在。

称重行为：
- 西方商人视角：人用物体A和系统B，使得产出数值x，x是物体C的某个属性的量化
- 阿坎人：是复杂的社会活动，铸件是作价标准，重量代表一定量金沙，用于交换税费/罚款/服务/货物。他们更像是在具体的行为中，为金钱估价。因而没有绝对的准确的统一的砝码。他们的砝码一个个形态各异，重量不同。

砝码中，窥见阿坎社会架构运作规律方式。
Tom Phillips 《African Goldweights》,他拥有4000多个砝码。阿坎砝码形象来源是社会生活的方方面面。
失蜡铸造。大量微雕。制作快速，因而可试验多种方法，试验各种题材。另一方面阻碍了大型雕塑的发展。

真实商场中交易（买几分钱与几斤重的交易），每次交易要花很长时间。买方和卖方都质疑对方的砝码重。也质疑每一粒金沙的纯度，和盛黄金的秤盘不够低。加纳中部城市库马西禁止女性摸秤，会挑出不满意的金沙要求重新称重。

4- 国际单位制-背景

法国国家档案馆：

  • Marie Antoinette和国王路易16的书信
  • 现行宪法
  • 1789《人权宣言》第一稿
  • 1791国民议会起草的《宪法》
  • 法国国民公会制作的1799年交给法国政府的【米和千克】的标准模具。人类此前从未制造过这种东西。圆棒和圆柱体，上面没有刻度和标志。
  • 欧洲各国统治者都推行过单一计量制。国内，宫廷与乡村，公司与行会，都有不同的规定。商贸荟萃/需求更新快的地区，有若干不同的多样的共存的度量衡制度。
  • 葡萄园，操场，麦地，大田，中的一天的工作量有不同的单位。劳动时间，肥沃程度，实际产出量，等等指标调控土地有效面积。
  • 机器零部件必须可以更换。部分人，可替换的部分。独立练习大腿，被动练习大腿肌肉机器。单独大腿锻炼，脑和手在另外的地方工作。
  • 非雕像/调音器，计量独立出，计量功能成了财富。
  • 计量体系 -> 商品/标准程序替代手工制品。
  • 市场扩张的动力 -> 统一度量衡的动力 -> 地域间交换关系（商业）的规模
  • 库拉评价公制计量单位体现：人人平等，商品的异化
  • 17世纪科学催生了【空间】的概念

音律

音名、音级功能、不同国家之间的对应关系，提供了强约束；但“大三度”这类关系名称，本身还可能容纳不同的精确大小：
- 纯律大三度：5∶4，约386.31音分
- 十二平均律大三度：400音分
- 五度相生律大三度：81∶64，约407.82音分
也就是说，我们可以知道两点在音阶结构中怎样关联，却尚未唯一确定它们之间的声学距离。

阿坎文明用交易时砝码雕像的形象表示交易时候的思想，是否是有扎实证据的

核心结论：

  • 计量工具也能携带文化记忆
  • 阿坎的金砂称量器具与相关小雕塑，把物质计量和谚语文化联系起来；部分造型可以在交往中唤起共同的社会判断。但不能笼统认定，每次交易都通过选择砝码形象来编码交易者的思想。
1-研究的话题严格表述
  • 阿坎诸群体（多个群体和王国）制作黄铜砝码，用天平称量作为交换媒介的金砂。
  • “造型具有寓意”和“交易者当场用它表达这次交易的想法”是两种不同强度的说法
  • 交易者特意选择某个造型，表达这一次交易中的具体立场。不能因为和谚语有关，就直接推出这个结论。
  • “交易环境中的器物可以承载社会表达”有研究支持。
  • “在交易中借造型与谚语表达观念”有比一般图像联想更直接的支持。
2-某些造型承载谚语、处世原则与社会观念：有可靠依据。
  • 例如，大都会博物馆的一枚象形砝码，被联系到这样的谚语：跟随大象的足迹行走，就不会被灌木上的露水打湿。图像由此可以唤起关于庇护、力量与追随的思考
  • 一个图形，对应多条相关谚语
  • 更强的说法，例如“买方拿出某种动物，就是在提醒卖方诚实”，还需要看到具体的民族志记录：谁在什么场合这样使用，当事人怎样解释，对方是否如此理解。仅凭造型与谚语的对应，不能把这个交易现场补出来
  • 大都会博物馆2025年的说明指出，被统称为“金砂砝码”的具象小雕塑，可能有不少实际是引发谈话、承载谚语与道德判断的器物，并未用于称重；有些则确实经过增减材料以校准重量。因此，连“它当时是否真是交易砝码”，都应逐件判断
3-造型传达的信息引导谈话的例子1个
  • 西雅图艺术博物馆明确描述，阿桑特的黄金交易会结合小雕塑展示与谚语言说，造型传达的信息能引导谈话；该馆还请在阿桑特王廷成长的音乐家Daniel Koo Nimo Amponsah解释Sankofa鸟的多种寓意。
  • “在交易中借造型与谚语表达观念”有比一般图像联想更直接的支持。仍需保留的限制是：这是结合本土知识持有者解释的博物馆研究说明，并非对某一历史交易的逐次观察记录，也不证明所有造型都具有固定、通行的交易含义
4-雕塑器物确曾被描述为传递具体诉求的媒介的例子1个
  • 民族志证据：Garrard的《Akan Weights and the Gold Trade》（1980，第201—202页）收录当地人的说明，称砝码可以像信件一样送给他人；其中以“蟹钳”造型为例，说明如何向另一位首领表达坚持索取补偿的立场。Pietz在1985年论文第16页注36转引了这段材料
  • 这支持“雕塑器物确曾被描述为传递具体诉求的媒介”，证据比单纯的寓意说明更进一步。不过该段是讲述使用方式的证言，采用假设举例，并非记下某次已发生的市场交易。限制器物与诉求的关联属性，最稳妥的范围是商业与社会交往中的观念、义务和诉求表达
