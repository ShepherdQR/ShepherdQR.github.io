推荐阅读路径

路径A

  • 阶段I：红研所校注本 + 王昆仑《红楼梦人物论》深化人物理解 + 蔡义江《红楼梦诗词曲赋鉴赏》理解判词与伏笔 + 脂砚斋评语辑校（陈庆浩）
  • 阶段II（文本肌理与学术视野）：庚辰本脂评本（对照脂批） + 周汝昌《红楼梦新证》（曹学与版本框架）+ 不同方法论的对话（余英时《红楼梦的两个世界》、张爱玲《红楼梦魇》、胡适《红楼梦考证》、俞平伯《红楼梦辨》）
  • 阶段III（学术）：精读甲戌本、庚辰本影印本及《石头记会真》 → 朱一玄《红楼梦资料汇编》做文献基础 → 刘梦溪《红楼梦与百年中国》、陈维昭《红学通史》建立学术史坐标 → 长期跟踪《红楼梦学刊》

路径B：人文社校注本 -> 庚辰/甲戌脂本 -> 胡适/俞平伯 -> 张爱玲 -> 王国维 -> 周汝昌 -> 余英时 -> 版本学 -> 近几十年的叙事学、性别史、物质文化史研究。

A类：底本

两大系统：

  • 脂评本：八十回抄本系统，以甲戌本、己卯本、庚辰本、戚序本为代表
  • 程高本（一百二十回排印本系统，分程甲本、程乙本）
  • 人民文学出版社"中国古典文学读本丛书"《红楼梦》（中国艺术研究院红楼梦研究所校注，通称"红研所本"，冯其庸等重构的），它以庚辰本为前八十回底本、程甲本为后四十回底本，兼顾原貌与完整性，是公认的权威通行本。
  • 程乙本（1792年程伟元、高鹗整理印行的全本。启功注释本，人文社/中华书局）。鲁迅、张爱玲读的就是这个系统。胡适，白先勇推崇。
  • 【大尺度主体】《脂砚斋重评石头记》庚辰本（78回）影印/汇校本。【正文 + 批语 + 修改痕迹 + 尚未定型的作品结构】
  • 【局部高分辨率切片】《脂砚斋重评石头记》甲戌本（16回）影印/汇校本【大量脂批】
  • 周汝昌《石头记会真》

脂批

  • 藏着大量关于曹雪芹生平、原稿结局（"草蛇灰线""狱神庙""情榜"）的线索，是红学一切考证的源头。
  • 涉及：作者信息；创作过程；佚稿线索；情节伏笔；人物评价；写作技法；早期接受史。
  • 需要谨慎对待：脂砚斋是谁、批语形成时间、不同批者的身份和可信程度

脂本

  • 清华版《红楼梦脂评汇校本》。豆瓣评分高达9.9分，被誉为“脂本普及的良心”。
  • 《脂砚斋重评石头记》（庚辰本影印，或邓遂夫校订本）——脂砚斋评语与正文一起读，是理解曹雪芹原意最直接的途径。甲戌本、己卯本可作对看。
  • 俞平伯《红楼梦八十回校本》——只保留八十回，不掺后四十回，便于看清"原书止于何处"。

B类：总论

价值：定义此后100年的问题空间

红学四大流派——评点派、索隐派、考证派、小说批评派——各自有其开山之作。

  • 王国维《红楼梦评论》（1904）：1904年以叔本华悲剧哲学解读《红楼》，是小说批评派的开端，也是中国近代文学批评的先声。提出“第三种悲剧”说，奠定了《红楼梦》的世界级美学地位。【欲望，痛苦，解脱，悲剧，审美，叔本华。从言情小书，提升到关于人的存在结构的悲剧哲学。理论起点】
  • 蔡元培《石头记索隐》（1917）：索隐派代表，主张"吊明之亡，揭清之失"的政治小说说，与胡适针锋相对，是了解旧红学的必读文献。提出“康熙朝政治小说”说。【代表索引派的高水平形式。作为一种 historical epistemology 来读。即研究：一个时代为什么会如此解释小说。】
  • 胡适《红楼梦考证》（1921）：1921年发表，确立"自传说"，考证出作者为曹雪芹、后四十回为高鹗续补，开创新红学。【从索引（映射什么），转向历史考证（作者，版本，文本形成时期，证据）。奠定现代红学范式】
  • 俞平伯《红楼梦辨》（修订版名《红楼梦研究》）（1923）：新红学另一奠基之作，对高鹗续书、八十回本系统辨析精细，俞氏后来也由此转向小说批评派。【80-40问题，高鹗问题，文本内部证据，情节结构，版本差异，作者意愿与续书关系。在胡适打开的问题的基础上，开始深入文本内部】
  • 鲁迅《中国小说史略》相关章节：对《红楼梦》"如实描写，并无讳饰"的评价言简意赅，是文学史定位的标杆。史家眼光。【接受史研究。reception theory：文本*读者->意义。意义产生机器。】

C类：文献考据类--曹学与版本学的核心

考据派是二十世纪红学正统，聚焦曹雪芹家世、版本流传、脂批等实证问题。

  • 周汝昌《红楼梦新证》：考证派集大成之作，构建"曹学"体系，考证曹家与康雍乾政治的关联；周氏由此提出"曹学、版本学、脂学、探佚学"四大分支，奠定了新红学的研究框架。2025年中华书局推出增订重排本，仍是研究者的必备参考书。【曹学 + 家世研究 + 文献考证 + 版本线索 + 清代制度史。试图把书嵌回曹雪芹家族—清代政治—江南织造—满汉社会—18世纪文化网络。文学是历史关系网络中的生成物。必须批判阅读，清醒这是一种玩法，不是真历史】
  • 周汝昌《石头记会真》：与兄长周祜昌历时五十余年的汇校巨著，十卷本，对存世各脂本做了系统比对，是版本研究的集大成。
  • 朱一玄《红楼梦资料汇编》（南开大学出版社）：辑录作者、版本、评论、影响四编史料，与一粟编《红楼梦书录》《红楼梦卷》互为补充，是文献检索的常用工具。
  • 张爱玲《红楼梦魇》："十年一觉迷考据"，以小说家之眼细辨各抄本异同与成书过程，主张《红楼梦》"是创作不是自传"，视角独特，文字精妙。【非常现代的文本发生学思维，作品的生成动力学。为什么这里重复？为什么某一人物突然改变？为什么一个伏笔后来没有兑现？为什么两个版本的差异不像“抄错”，而像“作者改写”？】
  • 刘梦溪《红楼梦与百年中国》：梳理百年红学十七次论争、九桩公案、三条不解之谜，相当于一部"红学概论"，是把握红学史脉络的最佳入门。
  • 冯其庸《石头记脂本研究》。脂本版本研究的权威著作，系统考证了甲戌、己卯、庚辰等各脂本的源流与传承关系，论证了庚辰本的底本价值，是版本学领域的标杆。
  • 冯其庸《曹雪芹家世新考》。
  • 吴世昌《红楼梦探源》。从版本、脂评、作者、续书四个维度全面考证，提出脂砚斋即曹雪芹叔父曹硕、续书作者非高鹗等独到观点，在国际汉学界影响深远。
  • 吴恩裕《曹雪芹丛考》——关于曹雪芹生平、交游、著书的材料与考辨。
  • 一粟《红楼梦卷》（古典文学研究资料汇编）——清代评点、序跋、笔记资料的总汇，写论文必备。

D类：文本批评·鉴赏类--回到小说本身

跳出考据回到文学本体，这一类最宜反复涵泳。

  • 《脂砚斋重评石头记》批语：最早的"弹幕"，透露了大量后四十回佚稿线索与曹雪芹创作意图，是精读必备。
  • 【结构分析】王昆仑《红楼梦人物论》：以现代视角剖析王熙凤、贾宝玉、林黛玉等人物，笔力老到，是人物论的典范。【严肃人物结构分析，建立《红楼梦》人物批评的一种基本语言】
  • 蔡义江《红楼梦诗词曲赋鉴赏》（中华书局）：收录各本诗词曲赋最全，每首附说明、注释、鉴赏，尤其善以脂批探佚诗中人物命运，配套原著阅读极佳。
  • 【高阶结构分析】【海外红学】余英时《红楼梦的两个世界》：提出大观园"干净理想世界"与园外"肮脏现实世界"的新范式，反思索隐派与自传说的局限，是海外红学的代表作。【理想/现实，青春/成人，洁净/污浊，情/历法，暂时乌托邦/历史时间。让《红楼梦》的空间结构有强的文明史-思想史结构意义】
  • 何其芳《论红楼梦》、蒋和森《红楼梦论稿》：上世纪五六十年代美学批评的代表作，注重艺术感染力的分析。
  • 夏志清《中国古典小说史论》（红楼梦卷）。西方汉学界研究《红楼梦》的代表作，从叙事结构、悲剧意识、宗教维度等角度切入，对比西方小说的视野极具启发性。
  • 舒芜《红楼说梦》
  • 蒋和森的相关论著
  • 李希凡、蓝翎《红楼梦评论集》。【批评史研究。《红楼梦》如何被20世纪中国的政治、社会史和文学理论重新编码。代表20世纪中国大陆一个极重要的马克思主义文学批评阶段。阅读要有阅读谱系意识，历史意识。】
  • 刘再复《红楼四书》等现代思想性研究。不应作为文献考证读，而应作为一种现代 philosophical reading。【人性，情，审美，生命伦理，女性世界，反功名结构】

E类：工具资料【诗词、语言、典制】

  • 陈庆浩《新编石头记脂砚斋评语辑校》。 目前最完备的脂评汇校本，将所有脂本的评语按回目整理汇编，标注版本差异，是研究脂评的必备工具书。
  • 一粟《古典文学研究资料汇编·红楼梦卷》。收录了从清代到20世纪中期的所有重要红学资料，包括序跋、评点、笔记、论文，是红学研究的基础资料宝库。
  • 陈维昭《红学通史》。系统梳理两百多年红学发展的完整历史，对各个流派、重要论争都有清晰评述，是了解红学全貌的最佳入门史学著作。

F类：专题研究

  • 邓云乡《红楼风俗谭》：清代名物、风俗、服饰、饮食的细节考证，生动可读。
  • 关华山《红楼梦中的建筑与园林》：建筑学视角解析大观园空间。
  • 周汝昌《红楼小讲》：通俗讲稿，适合作为研究者著作中最易读的入门。
  • 陈维昭《红学通史》：了解红学学术史整体演进的进阶读物。
  • 《红楼梦学刊》：1979年创刊至今，是追踪前沿研究的主要学术期刊。

G类：科普

  • 周汝昌《红楼梦与中华文化》《红楼小讲》——后者适合初读者，讲得亲切。
  • 蔡义江《红楼梦诗词曲赋鉴赏》——书中诗词谶语极多，不读注解会漏掉一半信息/隐式结构。【人物命运编码，叙事预示系统，象征系统，文体切换机制，作者控制 reader information 的工具】
  • 欧丽娟《大观红楼》——对人物（尤其宝黛钗、王熙凤）的细致分析，学术性与可读性兼顾。
  • 蒋勋《蒋勋说红楼梦》——最轻松的入门，适合把文本重新读一遍、找回感受力。

如果真正做研究：还要进入版本学【GPT6Astra-middle】

这一层非常重要，而且大众红学常常恰恰缺这一层。

至少需要理解：

甲戌本—己卯本—庚辰本—戚序本—蒙府本—甲辰本—程甲本—程乙本

之间的关系。

其中甲戌、己卯、庚辰是核心早期脂评系统；庚辰本现存回数最多，而程甲、程乙则属于后来120回刊本系统。

推荐再加入： 冯其庸《论庚辰本》以及他的版本研究文章。

这才真正开始进入：

什么叫“一个文本”？

这个问题。

红楼版本学其实可以看成一个很漂亮的 stemmatics / textual phylogeny problem：

设版本集合

$$ V=\{v1,\dots,vn\}, $$

每个版本包含：

$$ T_v=(正文、异文、缺文、批语、回目、页码结构、抄写错误) $$

那么研究目标之一，就是从 observable witnesses 反推不可见的 manuscript genealogy：

$$ \{Tv\}\Rightarrow G{\text{transmission}} $$

但《红楼梦》的困难在于：

它不是单纯“共同祖本→抄写分叉”。

其中还叠加了：

  • 作者自身改稿；
  • 不同时期稿本；
  • 抄手错误；
  • 后人改动；
  • 批者修改；
  • 合并不同来源稿本。

所以它更像一个 DAG / reticulate textual evolution，而不只是树。

这其实是红学最 intellectually interesting 的问题之一。

根问题

text ontology：我们今天所谓《红楼梦》，究竟是什么文本？

八十回？一百二十回？

《石头记》还是《红楼梦》？

哪个版本？

有没有唯一“原著”？

文本生成理论

人类，怎样不断把一个文本变成另一个文本

八十回以后发生了什么？

这是红学最大的 inverse problem 之一。

已知：

  • 前八十回伏笔；
  • 判词；
  • 曲文；
  • 脂批；
  • 人物轨迹；
  • 若干版本资料；

要求反演：lost ending

但这是严重 underdetermined 的问题。

因此“探佚”永远必须区分：evidence 和 reconstruction

《红楼梦》究竟在写什么？

不同尺度下的 coarse-graining：

  • 家族兴衰
  • 青春消逝
  • 女性世界
  • 情与礼
  • 欲望与幻灭
  • 贵族文明终结
  • 个体与制度
  • 记忆与时间
  • 存在与虚无

《红楼梦》为什么具有如此异常的文学复杂度？

  • 人物网格
  • 物质细节
  • 空间拓扑
  • 时间结构
  • 诗词预言
  • 伏笔
  • 对称
  • 重复
  • 隐喻

如何共同形成一个巨大 narrative system。

大观园甚至可以看成一种高度压缩的有限世界模型。

为什么两百多年的人不断重新解释它？

《红楼梦》不仅是一部小说，而且成为中国文明不断观察自身的一面镜子。
