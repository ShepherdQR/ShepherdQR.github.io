[科学史译丛]书目

Created 2026-10-26Published 2026-10-26Updated 2026-10-26
  • 商务印书馆"科学史译丛"由科学史翻译家张卜天担纲主译，自2016年起陆续推出，目前已出版约22种，是国内规模最大、体系最完整的西方科学史译介工程之一。

内容：

  • 西方科学思想史
  • 科学革命研究
  • 科学与宗教
  • 神秘学传统
  • 古代与中世纪科学

选购路径建议

  • 入门首选：《新物理学的诞生》《世界的重新创造》《重构世界》《现代科学的诞生》——篇幅适中、叙事流畅，可在两周内读完并形成科学革命的整体图景。
  • 进阶经典：《从封闭世界到无限宇宙》《世界图景的机械化》《科学革命的编史学研究》——科学思想史学派的核心文本与集大成之作，建议按此顺序递进阅读。
  • 专题延伸：关心科学与宗教读哈里森三部曲；关心神秘学炼金术读《西方神秘学指津》《炼金术的秘密》《西方神秘学传统》；关心中西比较读《文明的滴定》《金花的秘密》。
  • 学术研究必备：《科学革命的编史学研究》《西方科学的起源（第二版）》《近代科学在中世纪的基础》——直接面向研究者，文献密度高，可作工具书使用。

版本与查询提示：丛书以精装32开为主，部分品种（《牛顿研究》《文明的滴定》《从封闭世界到无限宇宙》等）同时收录于商务"汉译世界学术名著丛书"，存在多个印次与定价，购买时以最新印次为准。丛书仍在持续扩充中，最新书目可在商务印书馆官网（www.cp.com.cn）"丛书"栏目下的"科学史译丛"页面查询。

第一辑（蓝皮本，2016年，共6种）

书名作者分类推荐说明
《文明的滴定：东西方的科学与社会》李约瑟比较科学史 / 中国科学史8篇论文结集，完整表述"李约瑟问题"，是理解中西方科学发展差异的经典入口
《牛顿研究》亚历山大·柯瓦雷科学思想史 / 17世纪科学革命柯瓦雷生前审定的最后一部著作，由7篇论文组成，示范了"概念分析"方法的巅峰之作
《从封闭世界到无限宇宙》亚历山大·柯瓦雷科学思想史 / 宇宙论科学思想史学派奠基之作，主线是"Cosmos的解体"与"空间的几何化"，回答现代世界观如何诞生
《科学与宗教的领地》彼得·哈里森科学与宗教吉福德演讲修订稿，论证"科学与宗教对立"其实是19世纪才形成的观念，颠覆常识
《新物理学的诞生》I.伯纳德·科恩科学革命 / 物理学史1543—1687年哥白尼至牛顿的通俗叙事，陈嘉映推荐"纲目最为清楚"，入门首选
《自然科学与社会科学的互动》I.伯纳德·科恩跨学科 / 科学社会学讨论近300年自然科学与社会科学的概念、方法互借，对理解"社会科学的科学化"极有价值

第二辑（红皮本，2018—2019年，共6种）

书名作者分类推荐说明
《世界图景的机械化》爱德华·扬·戴克斯特豪斯科学思想史 / 数理科学史获荷兰国家文学奖霍夫特奖，从毕达哥拉斯写到牛顿，782页鸿篇巨制，"科学革命概念"三位缔造者之一的代表作
《近代物理科学的形而上学基础》埃德温·阿瑟·伯特科学哲学 / 科学思想史1924年经典，回答"为什么认识论问题成为近代哲学的中心"，既是科学史也是哲学史
《西方科学的起源（第二版）》戴维·林德伯格古代与中世纪科学关于1450年前欧洲科学的最权威教科书，萨顿奖得主作品，覆盖希腊、伊斯兰、拜占庭科学
《圣经、新教与自然科学的兴起》彼得·哈里森科学与宗教论证新教"字面释经"方式如何为中世纪象征世界观画上句号，为近代科学兴起创造条件
《西方神秘学指津》乌特·哈内赫拉夫神秘学国内首部系统阐述西方神秘学的导论，覆盖灵知主义、炼金术、占星术、玫瑰十字会等"被拒知识"
《炼金术的秘密》劳伦斯·普林西比炼金术史 / 化学史学术性与趣味性兼备，作者在实验室重现许多炼金术配方，是了解炼金术的最佳读本

第三辑（绿皮本，2019—2020年，共6种）

书名作者分类推荐说明
《重构世界》玛格丽特·J.奥斯勒科学革命 / 中世纪—近代过渡短小精悍的过渡期思想史，在柯瓦雷纲领之外补入炼金术、占星术与自然志传统，篇幅仅239页
《近代科学在中世纪的基础》爱德华·格兰特中世纪科学萨顿奖得主作品，颠覆"中世纪一团漆黑"的刻板印象，论证近代科学的诸前提在中世纪晚期已准备完毕
《近代科学的建构：机械论与力学》理查德·韦斯特福尔科学革命牛顿权威传记作者所写的教科书，强调"柏拉图主义—毕达哥拉斯主义"与"机械论"两主题的张力
《世界的重新创造：现代科学是如何产生的》H.弗洛里斯·科恩科学革命提出"雅典模式—亚历山大模式—文艺复兴模式"框架，是理解科学革命起源的最佳通俗读物
《无限与视角》卡斯滕·哈里斯哲学 / 现代性批判耶鲁哲学教授作品，把哲学史、神学史、艺术史熔为一炉，论证现代性植根于基督教关于"上帝无限性"的反思
《人的堕落与科学的基础》彼得·哈里森科学与宗教论证基督教"原罪观"如何催生了实验方法与人工仪器，是哈里森三部曲中论点最锐利的一部

第四辑（褐皮本，2021—2025年，共4种）

书名作者分类推荐说明
《希腊科学》杰弗里·劳埃德古代科学劳埃德两部经典《早期希腊科学》《亚里士多德之后的希腊科学》的合订本，剑桥古代科学权威的简明入门
《科学革命的编史学研究》H.弗洛里斯·科恩科学史学史 / 工具书全书969页，系统考察19世纪以来关于"科学革命"实质与原因的约60种观点，是该领域唯一一部百科全书式研究著作，研究者必备
《现代科学的诞生》保罗·罗西科学革命意大利科学史泰斗、萨顿奖得主作品，重视魔法传统与技术传统对科学革命的贡献，是对经典叙事的重大修正，兼作理想的入门读物
《时间的发现》斯蒂芬·图尔敏、琼·古德菲尔德思想史 / 时间观念史2025年新书，追溯人类如何从静态宇宙观转向演化世界观，跨哲学、地质学、生物学，是商务2025年学术类重点新书
