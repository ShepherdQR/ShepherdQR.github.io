191211,法国工人诗人鲍迪埃（国际歌作者）。
2026-08-30 21:31:33
1840年起，用战斗歌曲：反应法国生活事件，唤醒落后人们的觉悟，号召工人团结，鞭笞法国资产阶级和资产阶级政府。
国际歌，是187106，5月流血失败后第二天写的。
  • 列宁：鲍迪埃是用歌作为工具的宣传家。
  • 本书，选了 20 首。

Abstract

Content

让思想冲破牢笼。
英特纳雄耐尔，就一定要实现。
//济贫院，贫民习艺所。以救济的名义，欺骗和剥削的机构。
//18701031，布朗基派发动起义，占领巴黎市政厅。准备建立公社，后失败。

铁路和运河，矿山和土地
电报/汽船/工厂，一切生产工具，
所有权应当掌握在我们手里！

我又做了工资的奴隶，
没有姓名的主人叫我干一天活拿一天钱。
我又变成了当牛做马的平民，
眼睛看不见光明，心里感不到温暖。

// 资本家将机器变为剥削和压迫的工具

眼前是悲惨的生活，
眼前是沉重的压迫，
起义者，
起来，子弹上膛，准备开火！

// 1879年马赛代表大会，通过了建立工人党和指定党纲的决议。

是你用剩余劳动把商场装满。

繁荣，自由，平等。

芽月。// 公历0321或0322，到0419或0420

尼古拉，公社并没有死亡！//尼古拉是普通名字，这里泛指。

// 小仲马，法国资产阶级作家，凡尔赛分子。 // 凡尔赛分子屠杀巴黎公社约10w人。


《美国工人致法国工人》——出席1876年费城博览会的自由代表团【长诗。节选】
// 18760510，纪念美国建国100年，第6届世界工业博览会在费城开幕。
敬礼，社会问题！
敬礼！问题多得无数。

生产和果实的分配。

许多舒适的家具也摆在那里，...
使卖淫的行为更精致，更刺激，
（这在各国流行，变成了秩序和常规。）
费城这样，两年后巴黎也将如此。

人怎能受商业支配！

【END】
