风雅俳句

Created 2022-06-02Published 2023-02-12Updated 2023-02-12

郑民钦翻译的，分为春夏秋冬四小本。

1908年大须贺乙首次用“季句”，指形成季节核心的自然物象。徘谐、俳句重视日常生活中的季节感。

松尾芭蕉（1644-1694），俳圣，革新徘谐，用于表现内心生活。

与谢芜村（1716-1783），小林一茶（1804-1829）。

新兴俳句、无季俳句、连作俳句、自由律、社会性俳句、前卫俳句。

传统俳句：十七音、切字、季语。

辛酸的哀叹，凄楚的诉说，苦涩的揶揄，不平的愤懑，暗淡的绝望，低沉的颓丧。

【荒木田守武】 疑是落花返枝头，一看原来是蝴蝶。

飞梅轻飘天神春，满眼乌鸦和黄莺。

【松尾芭蕉】 古池，青蛙入水声。 //古池是“过去”的凝结，有幽深的秘密，入水是现在的活动，打破了千古的沉默。后面的无声与先前的无声有本质的不同。

云峰几度散，明月照月山。

羁旅病床箦，梦绕荒野枯。 // 辞世句

枯枝栖寒鸦，晚秋日暮斜。

马睡残梦月远茶烟。

惊涛骇浪掀大海，银河横卧佐渡天。

此道无人行，不觉秋已暮。

【腹部岚雪】 寒梅开一朵，一朵一份暖。 //日本说花一般指硬化，奈良时代指白梅，平安时代指红梅。

【小西来山】 银鱼自在游，仿若水色动。

我若追求风，秋风沁我身。

【榎本其角】 欢乐赏樱花，酒为妻子妻为妾。

今宵秋月圆，松影映照榻榻米。

【与谢芜村】 鲜妍、唯美、浪漫 樱花凋谢后，寺院坐落在林间。

春之海，竟日轻轻荡漾。

东边新月，西边夕阳，中间是无际的金黄色的菜花。

晚霞草迷蒙，流水无声。 // 无纤尘的明净，水无声的幽远。

【大岛蓼太】 不见方三日，世上满樱花。

【高桑阑更】 枯芦苇，日日折断随流去。

【加舍白雄】 蝴蝶飞越小河引起晚风吹拂。

雨水滴答透薄冰。

不修饰别人，不修饰自己，不修饰文章。

盲女看不见盛开的木槿花，不知道已经傍晚了，心灵寂寞，木槿树也显得孤独。

【小林一茶】 撒把米也罪过，引来群鸡争斗。

积雪融化后，满村都是小孩子。

迢迢回故乡，野蔷薇花处处开。

【村上鬼城】 早春尚嫩寒，盲犬行走撞着墙。

死无葬身地，冬蜂到处走。

【高滨虚子】 蝴蝶啮物静悄悄。

生为蜘蛛，须结网。

【臼田亚浪】 风穿树间春处浅。

【前田普罗】 拜佛眼睛观柱枯。

【尾崎放哉】 一日无语观蝶影。

没有盛的东西就用双手接吧。

咳嗽也一人。

【川端茅舍】 极光净土界。

朴树散花，不知去向。 // 辞世句

石上一滴金刚露。

【日野草城】 握住一把种子，生命躁动掌中。

只眼已失明，犹擦眼镜片。

秋夜深，钥匙钻进红茶里。

【高井几董】 涉水过河女，小腿沾藻花。

【夏目成美】 闲来无聊打苍蝇，忽起杀尽苍蝇心。

【葛饰北斋】 余将化人魂，夏日散步原野上。 // 辞世句

【正冈子规】 丝瓜花盛开，痰堵成佛去。// 辞世句共3首 无济丝瓜水，难止一斗痰。 前天十五夜，未取丝瓜水。//当时习俗连续喝15天丝瓜水可祛痰，前天没有取。

【夏目漱石】 敲木鱼，吐出白日蚁。

别梦一条银河阔。

秋去也，一卷书籍未读完。

冬日狂风寒，夕阳吹落海。

【大田南亩】 白日敲木鱼，吐出蚊子来。

【饭田蛇笏】 盛夏中午，死神看人，半睁半闭眼。

药香随命尽，寒冷飘散去。

【原石鼎】 初夏一只蝶，飞过我瞳海。

【芥川龙之介】 似梦非梦听松涛，一顶遮阳帽。

【富泽赤黄男】 时间，只长着两颗草。 // 只张着两棵草的世界，无限的时间流逝，一切都虚无。

没有脑袋的孤独，可是鸡的飞跑。

蝉蜕终于，变成风的咒文。

黑手放在云彩上，夏天觉疲劳。

树梢渐枯萎，凝视黑墓碑。

【大伴大江丸】 两个涩柿子，各自摘一个。

【尾崎红叶】 星星已经睁秋眼。

【久保田万太郎】 秋来渐觉凉，灯影随身行。

【内藤丈草】 苍鹰锐目矩如电，凝射枯野朔风寒。

【黑柳召波】 海蜇烦恼事，细与海参说。

【河东碧梧桐】 母亲哟，戴着手套锯木炭。

【西东三鬼】 苦恼失眠症，鱼在远海游。

【其他】 埃兹拉庞德：人群中那些脸庞的隐现，湿漉漉、黑黝黝的树枝上的花瓣。

白居易：忧方知酒圣，贫始觉钱神。

杜牧：霜凝孤鹤迥，月晓远山横。
